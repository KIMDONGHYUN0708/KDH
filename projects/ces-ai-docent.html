02 · 도슨트 경험 설계 판단 3가지

경험 01 · AEM 글로벌 전시 페이지

AEM 컴포넌트와 HTML 영역을 결합한 글로벌 전시 페이지 구축

전시 메시지에서 전시존별 콘텐츠와 오디오 도슨트로 이어지는 정보 구조를 설계했습니다. AEM 컴포넌트를 직접 생성하고 자율형 영역에 HTML·CSS 소스를 적용해, 동일 URL에서 단계별 콘텐츠를 전환하는 페이지를 구축했습니다.

경험 02 · AI 오디오 도슨트

5개 언어로 제공한 전시존별 AI 오디오 도슨트

영어·중국어·일본어·스페인어·프랑스어로 전시존별 오디오 콘텐츠를 구성했습니다. 언어별로 ElevenLabs와 Baidu TTS를 적용하고 이미지·설명·오디오·만족도 조사를 한 화면에 담아, 현장과 온라인에서 동일한 경험을 제공했습니다.

경험 03 · 현장·데이터 접점

오디오 진입과 유입 측정을 분리한 전시존 QR 설계

공통 QR과 전시존별 QR의 설치 위치·연결 콘텐츠를 구분했습니다. QR별 파라미터와 GA 이벤트를 적용해 오디오 도슨트로 연결하고, 유입 위치와 청취 행동을 측정했습니다.

03 · 기획 산출물

전체 페이지 구조 안에서 도슨트의 위치를 정의하고, 단계별 전환 시점을 계획했습니다.

CES 2025 메인 페이지의 배너 구성 중 AI 도슨트(오디오 가이드) 진입 배너의 위치와 연결 구조를 정의한 문서

유입 경로와 URL을 유지하기 위해 별도 페이지 생성 없이, 티징·행사 오픈·아카이브 단계별 노출 콘텐츠와 전환 시점을 정의한 운영 계획

AEM 컴포넌트를 직접 생성하고, 실제 페이지 메타데이터까지 정의했습니다.

AEM 컴포넌트와 자율형 HTML 영역의 역할·배치를 정의하고, 실제 운영 환경에서 구현 가능성과 노출 이슈를 직접 검증한 페이지 구축 계획

OG·Twitter 메타데이터와 SEO 설정을 직접 구성하고, 구글 검색 노출 결과까지 확인한 페이지 설정 자료

언어별 지원 범위와 음성 품질을 비교해 TTS 적용 기준을 정의했습니다.

지원 언어·발음·음성 자연스러움·운영 안정성을 비교해, 영어·일본어·스페인어·프랑스어는 ElevenLabs를, 중국어는 Baidu TTS로 이원화한 선정 기준

콘텐츠 매트릭스로 글로벌 배포 기준을 세우고, 유입과 청취 데이터를 매일 확인해 행사 종료 후 결과 리포트로 정리했습니다.

국가별 KV 규격·메시지·연결 URL을 관리해 약 80개 글로벌 닷컴의 배포 기준을 세운 콘텐츠 매트릭스 (민감 정보 블러 처리)

전시존 QR 스캔 데이터를 측정하기 위해 QR별로 설계한 UTM 파라미터 관리 시트

행사 종료 후 배너 클릭·사이트 트래픽·오디오 도슨트 재생 데이터를 종합한 결과 리포트
