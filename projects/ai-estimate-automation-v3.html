01

담당자의 경험에 의존하던 견적 기준을 재사용 가능한 구조로 바꿨습니다.

기존에는 프로젝트 요청을 확인한 뒤 과거 견적서에서 유사 항목과 업무 범위를 찾고, 2026년 사내 직급별 표준단가표를 적용해 디자인·개발 인력의 맨먼스와 금액을 직접 계산했습니다. 요청마다 범위와 투입 인력을 판단하고 계산 결과를 엑셀 견적서에 작성해야 했기 때문에, 반복되는 산정 과정을 에이전트가 재사용할 수 있는 구조로 전환했습니다.

02

과거 기준 탐색부터 맨먼스 계산과 문서 작성까지 매번 반복됐습니다.

01프로젝트 범위에 필요한 디자인·개발 항목과 투입 인력을 매번 판단
02과거 견적서의 유사 항목과 사내 직급별 표준단가를 반복 확인
03직군·직급별 맨먼스와 금액을 계산해 내부 엑셀 견적서에 직접 작성
03

자연어 입력을 맨먼스 계산과 견적서 생성으로 연결했습니다.

01자연어 입력 · 프로젝트 범위·조건 또는 총예산 입력
02업무 항목 구조화 · 디자인·개발·장치·운영 항목으로 분해
03기준 참조 · 과거 견적의 유사 항목과 투입 범위 확인
04맨먼스·금액 산정 · 직군·직급별 맨먼스 구성 및 표준단가 적용
05범위·예산 조정 · 범위 기준 총액 산정 또는 총예산에 맞춰 조정
06견적서 생성·검토 · 엑셀 견적서 출력 후 담당자 최종 조정

프로젝트 범위를 입력하면 과거 견적서의 유사 항목을 참고해 필요한 업무와 투입 인력을 구성하고, 2026년 사내 직군·직급별 표준단가를 적용해 맨먼스와 총액을 산정합니다. 총예산이 정해진 경우에는 예산에 맞춰 업무 항목과 맨먼스를 조정하며, 결과는 내부 엑셀 견적서로 생성됩니다.

04

기존 업무 언어를 유지한 입력과 검토 가능한 결과물을 연결했습니다.

기능 01 · 요청 입력

한 줄 요청으로 견적 조건과 산정 방식을 입력

팀원이 별도의 입력 양식을 작성하지 않고 프로젝트 범위와 조건을 한 줄로 요청하면, 에이전트가 필요한 업무 항목과 투입 인력으로 구조화합니다. 총예산을 함께 입력하면 해당 금액에 맞춰 항목과 맨먼스를 조정하는 방식으로도 사용할 수 있습니다.

기획 의도: 별도의 입력 양식 없이 구축하려는 프로젝트를 설명하는 것만으로 견적 산정을 시작

기능 02 · 견적서 출력

맨먼스와 표준단가를 반영한 엑셀 견적서 생성

구조화한 업무 항목에 직군·직급별 맨먼스와 2026년 사내 표준단가를 적용하고, 항목·수량·단가·금액이 포함된 내부 엑셀 견적서로 생성합니다. 담당자는 프로젝트별 예외 항목과 최종 금액만 확인·조정할 수 있습니다.

기획 의도: 산정 결과를 다시 옮겨 적지 않고 실제 검토 문서로 바로 연결

05

자동화할 산정 과정과 담당자가 확인할 기준을 구분했습니다.

자동화 범위

과거 견적의 항목 구성과 사내 표준단가의 역할을 분리했습니다.

과거 견적서는 유사 프로젝트의 업무 항목과 투입 범위를 참고하는 기준으로 사용하고, 금액 계산에는 2026년 사내 직급별 표준단가를 적용했습니다. 참고 사례와 가격 기준을 구분해 산정 근거가 섞이지 않도록 했습니다.

입력 방식

업무 범위와 총예산 두 방향에서 견적을 구성했습니다.

필요한 업무 범위가 먼저 정해지는 경우에는 투입 맨먼스와 총액을 산정하고, 총예산이 먼저 정해진 경우에는 해당 금액에 맞춰 항목과 맨먼스를 조정하도록 설계했습니다.

최종 판단

산정 결과의 적합성은 담당자가 최종 확인하도록 했습니다.

에이전트는 업무 범위 또는 총예산을 기준으로 맨먼스와 견적 구조를 생성합니다. 담당자는 일정·난이도·고객사 협의 조건을 고려해 산정된 업무 항목과 투입 기준의 적합성을 최종 확인하도록 역할을 구분했습니다.

06

반복되던 견적 산정과 문서 작성을 하나의 자동화 흐름으로 전환했습니다.

자연어 한 줄을 업무 항목과 투입 인력으로 구조화하는 입력 흐름 구현

02

과거 견적의 유사 항목과 사내 직군·직급별 표준단가를 구분한 산정 구조 설계

03

범위 기반 산정과 총예산 기반 조정 결과를 내부 엑셀 견적서로 생성
