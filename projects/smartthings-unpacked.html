01 · 연동 흐름 — 안내에서 반응까지

짧은 관람 시간 안에 연결의 의미를 이해시켜야 했기 때문에, 관람객이 이전 단계에서 본 것을 다음 단계에서 직접 확인하도록 6단계 순서를 고정하고 각 단계의 화면 전환 조건을 구현 요구사항으로 정리했습니다.

02모바일 SmartThings 체험으로 유도
03모바일에서 기기 기능 제어

02 · 화면 설계 판단 2가지 — 신호 매핑과 시나리오 조율

경험 01 · 통합 화면 설계

SmartThings 제어 신호값별 미디어월 화면 상태 매핑

관람객이 모바일에서 SmartThings를 제어하면 해당 신호에 따라 미디어월 콘텐츠가 전환되도록 화면 상태와 반응 조건을 정리했습니다.

경험 02 · 시나리오와 UI 조율

사용자 행동·제품 상태·체험 카피를 화면 단위로 세분화

체험 시나리오를 화면별 상태와 전환 조건으로 분해하고, 제일기획 UI 담당자와 정보 우선순위·인터랙션·피드백 방식을 조율했습니다.

03 · 기획 산출물

SmartThings 신호값과 미디어월 반응을 청소 모드·무비 모드 등 시나리오별로 매핑했습니다.

청소·무비 모드 등 시나리오별 UX/UI 흐름과 전자제품 상태 변화를 함께 검토한 협의 문서

시나리오별 화면 전환 조건과 미디어월 비디오 콘텐츠 상태를 정리한 설계 문서

설계한 반응 시나리오가 실제 현장에서 그대로 구현된 모습입니다.

협의안의 청소 모드 화면이 실제 현장 미디어 테이블에 구현되어 운영된 모습

미디어 테이블 하드웨어·공간 시스템 구축과 체험 카피 관리까지 협업했습니다.

장비 접근과 유지보수를 고려해 상부 도어와 내부 수납 구조를 협의하고 관련 내용 메뉴얼화

실제 기기 간 연결도와 오디오 등 공간 시스템 요소를 정리한 설계 문서

전원·인터넷·HDMI 등의 연결선을 정리한 시스템 구성도 협의 문서

한·영문 체험 카피와 수정 이력을 시나리오별로 관리한 카피덱
